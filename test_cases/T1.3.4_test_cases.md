**Test Case 1: Meta Description and Title Tag Optimization**

*   **Title:** Verify Meta Description and Title Tag Population and Correctness

*   **Description:** This test case verifies that the `<title>` and `<meta name="description">` tags are populated on key website pages, are of appropriate length, and contain relevant keywords to accurately reflect the page content and attract search engine crawlers. This test will check the homepage, a product page, and a blog article page.

*   **Steps:**

    1.  **Navigation:**  Navigate to the homepage of the website (e.g., `www.example.com`).
    2.  **Source Code Inspection:**  Right-click on the page and select "View Page Source" or "Inspect" (and then navigate to the "Elements" tab if applicable) to view the HTML source code.
    3.  **Title Tag Verification:** Locate the `<title>` tag within the `<head>` section of the HTML.
    4.  **Meta Description Verification:** Locate the `<meta name="description">` tag within the `<head>` section of the HTML.
    5.  **Record Values:** Note the content within the `<title>` and `<meta name="description">` tags.
    6.  **Length Validation:** Verify that the length of the `<title>` tag is between 50 and 60 characters (inclusive).
    7.  **Length Validation:** Verify that the length of the `<meta name="description">` tag is between 150 and 160 characters (inclusive).
    8.  **Relevance Check:**  Confirm that the content of both tags accurately reflects the content of the homepage and contains relevant keywords related to the website's purpose.
    9.  **Repeat Steps 1-8:** Repeat steps 1-8 for a sample product page (e.g., `www.example.com/products/product1`) and a sample blog article page (e.g., `www.example.com/blog/article1`).

*   **Expected Result:**

    *   The `<title>` tag is present within the `<head>` section on all pages tested.
    *   The `<meta name="description">` tag is present within the `<head>` section on all pages tested.
    *   The `<title>` tag content is between 50 and 60 characters in length on all pages tested.
    *   The `<meta name="description">` tag content is between 150 and 160 characters in length on all pages tested.
    *   The `<title>` and `<meta name="description">` tag content accurately describe the content of the respective page.
    *   The `<title>` and `<meta name="description">` tag content contains relevant keywords related to the website's purpose and the specific page content.

*   **Priority:** High

**Test Case 2: Robots.txt File Validation**

*   **Title:** Verify Robots.txt File Implementation

*   **Description:** This test case ensures that a `robots.txt` file is present and configured correctly to guide search engine crawlers, allowing or disallowing access to specific sections of the website.  This helps optimize crawling behavior and avoid indexing sensitive or irrelevant content.

*   **Steps:**

    1.  **File Existence Check:** Navigate to the root directory of the website by appending `/robots.txt` to the base URL (e.g., `www.example.com/robots.txt`).
    2.  **File Content Verification:**  If the file exists, examine its content. Look for the following:
        *   `User-agent:` directives specifying which bots the rules apply to (e.g., `User-agent: *` for all bots, `User-agent: Googlebot` for Google's crawler).
        *   `Disallow:` directives specifying which URLs or directories should not be crawled.
        *   `Allow:` directives (optional) specifying which URLs or directories should be crawled, even if they are within a disallowed directory.
        *   `Sitemap:` directive (optional) pointing to the website's sitemap XML file.
    3.  **Disallow Validation:** Confirm that sensitive areas or pages (e.g., admin panels, duplicate content, checkout pages) are properly disallowed using `Disallow:` directives.
    4.  **Sitemap Validation:** If a `Sitemap:` directive is present, verify that the URL provided is a valid and accessible URL for the sitemap XML file.
    5.  **Negative Test (Optional):** If the `robots.txt` file allows crawling of a specific page (e.g., the homepage), attempt to access that page with a known bot (e.g., by using a user-agent switcher in your browser and impersonating Googlebot).  Verify that the page loads correctly.

*   **Expected Result:**

    *   A `robots.txt` file exists and is accessible at the root directory of the website.
    *   The `robots.txt` file contains appropriate `User-agent:` directives to target different search engine bots.
    *   The `robots.txt` file correctly disallows crawling of sensitive or irrelevant pages or sections of the website.
    *   If present, the `Sitemap:` directive points to a valid and accessible sitemap XML file.
    *   Pages intended to be crawled (as per the `robots.txt` file) are accessible when simulating a search engine bot.
    *   The robots.txt file is formatted correctly. (e.g. `Allow:` and `Disallow:` directives do not have spaces after them and before the directory or file path.)

*   **Priority:** High
