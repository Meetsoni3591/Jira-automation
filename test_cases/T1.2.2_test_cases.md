**Test Case 1: User Management - Create New User**

*   **Title:** Verify Admin can Create a New User with Valid Credentials

*   **Description:** This test case verifies that an administrator can successfully create a new user account through the admin panel with valid input data. The test includes verifying the user is created and can log in.

*   **Steps:**

    1.  **Pre-condition:** Ensure that the Admin user is logged in to the admin panel.
    2.  Navigate to the User Management section (e.g., "Users" or "Manage Users" in the admin panel).
    3.  Click on the "Add User" or "Create User" button.
    4.  Enter the following details into the user creation form:
        *   **Username:** `testuser123` (Ensure it's unique)
        *   **Email:** `testuser123@example.com` (Ensure it's a valid email format)
        *   **Password:** `StrongPassword123!` (Meets password complexity requirements)
        *   **Confirm Password:** `StrongPassword123!`
        *   **First Name:** `Test`
        *   **Last Name:** `User`
        *   **Role:** `Standard User` (or a role appropriate for testing)
    5.  Click on the "Save" or "Create" button.
    6.  Verify if a "User Created Successfully" message is displayed.
    7.  Log out the Admin user.
    8.  Attempt to log in with the newly created user credentials (Username: `testuser123`, Password: `StrongPassword123!`).
    9.  Log out the new user.

*   **Expected Result:**

    *   After Step 5: The new user account should be successfully created in the system. A success message ("User Created Successfully") should be displayed.
    *   After Step 8: The user should be able to successfully log in to the application with the provided credentials.

*   **Priority:** High (P1) - User management is a critical administrative function.

**Test Case 2: System Configuration - Update Application Title**

*   **Title:** Verify Admin can Update Application Title in System Configuration

*   **Description:** This test case verifies that an administrator can successfully modify the application title/name through the system configuration panel and that the change is reflected throughout the application.

*   **Steps:**

    1.  **Pre-condition:** Ensure that the Admin user is logged in to the admin panel.
    2.  Navigate to the System Configuration section (e.g., "Settings," "Configuration," or "System").
    3.  Locate the setting for "Application Title" or "Website Name".
    4.  Note the current application title.
    5.  Enter a new title in the input field (e.g., "New Application Title").
    6.  Click on the "Save" or "Update" button.
    7.  Verify if a "Settings Saved Successfully" message is displayed.
    8.  Refresh the admin panel or the main application page.
    9.  Verify the application title is updated at all places of the application as it is supposed to be (e.g., browser tab title, header, footer).
    10. Revert the Application Title to it's previous value.
    11. Click on the "Save" or "Update" button.
    12. Verify if a "Settings Saved Successfully" message is displayed.
    13. Refresh the admin panel or the main application page.
    14. Verify the application title is updated at all places of the application as it is supposed to be to the original value.

*   **Expected Result:**

    *   After Step 7: The system should save the new application title. A success message ("Settings Saved Successfully") should be displayed.
    *   After Step 9: The application title in the browser tab, header, and other relevant areas of the application should be updated to "New Application Title".
    *   After Step 12: The system should save the original application title. A success message ("Settings Saved Successfully") should be displayed.
    *   After Step 14: The application title in the browser tab, header, and other relevant areas of the application should be updated to the original value.

*   **Priority:** Medium (P2) -  While not as critical as user management, system configuration is important for branding and customization of the application.
